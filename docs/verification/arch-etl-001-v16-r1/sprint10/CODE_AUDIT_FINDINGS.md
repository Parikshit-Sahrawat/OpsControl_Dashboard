## Safeguards positively located

- [backend/app/security/http.py](../../../../backend/app/security/http.py) authenticates current token, resolves current access, chooses explicit scope and resets request contexts; [backend/app/security/access_control.py](../../../../backend/app/security/access_control.py) computes paired grants and denies, includes revision/provenance; [backend/tests/test_sprint08_rbac.py](../../../../backend/tests/test_sprint08_rbac.py) covers direct/inherited, ALL, scope restrictions, malformed persisted policies and revocation.
- [backend/app/unified/models.py](../../../../backend/app/unified/models.py) `ResourceDependency` uses composite customer/resource foreign keys, no-self and current-edge uniqueness constraints. `add_dependency` additionally checks environment, authoritative service/host identity, advisory serialization and cycles. Temporal retirement exists; this is not evidence of a complete historical snapshot/freshness product.
- [backend/app/unified/pentaho_recovery.py](../../../../backend/app/unified/pentaho_recovery.py) checks independent confirmation, revision and native supporting evidence. [backend/app/native_incidents/pentaho.py](../../../../backend/app/native_incidents/pentaho.py) checks downstream evidence/observation; manual recovery never rewrites original failure. Prior execution/review/incident tests and Sprint 06–09 gates are controlled evidence only.
- [backend/app/telemetry/ingestion.py](../../../../backend/app/telemetry/ingestion.py) streams a 2 MiB envelope bound, bounds expanded gzip, rejects malformed envelopes, bounds records and future timestamps, reauthenticates during store and retains authenticated collector identity. Residual clock/backpressure/fleet questions remain.
- [backend/app/worker/notifications.py](../../../../backend/app/worker/notifications.py) uses short fenced claims, capped retries and provider IO outside the claim transaction. Provider crash-window semantics still require measured acceptance.
- [backend/app/services/retention.py](../../../../backend/app/services/retention.py) uses bounded deletion batches/pinning; [backend/app/data_pipelines/runtime.py](../../../../backend/app/data_pipelines/runtime.py) preserves owner fences/checkpoints; [backend/tests/test_pipeline_ownership_v16.py](../../../../backend/tests/test_pipeline_ownership_v16.py) and Sprint 09 preservation/restart evidence support controlled behavior. Host/process failure is not certified.
- Frontend feed generation/abort guards and auth failures prevent prior-scope responses from replacing current data; existing browser evidence covers customer switching and denied actions. No new browser run occurred here.

## Review limits

This is representative inspection, not a whole-repository security certification. No code changes, exploits, data changes or broad refactoring were authorized/performed. Exact source recovery, independent review, real provider behavior, long-duration saturation, process kills, private-network failure and actual native Windows/systemd installation remain separate gates. Findings are defects, scalability findings, missing verification or open questions as labeled; none silently becomes a new approved improvement.
